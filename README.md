## 📖 Описание

**Триггербот для РП проектов** — программа, которая сама нажимает `ЛКМ`, когда цель появляется в центре экрана. Работает по цвету, без вмешательства в память игры 🧪

### ✨ Возможности

#### 🚀 Запуск за 1 минуту
1. 📸 Скриншот цели (`Win+Shift+S`)
2. 📋 Клик по области «Картинка прицела»
3. 🎨 Программа сама найдёт цвет и подберёт область
4. 🔥 Нажмите «Пуск»

#### ⚙️ Настройки
- 🎹 Любая клавиша или кнопка мыши для активации
- 🔁 Режимы **«При зажатии»** или **«Вкл/Выкл»**
- 🖱️ Клик — одиночный или зажатие
- 🎚️ Область, чувствительность, число цветов, интервал

#### ✨ Фишки
- 📊 Живой статус с подсказками «мало / много»
- 🔒 Настройки блокируются во время работы
- 💾 Автосохранение
- 🌍 Интерфейс RU / EN

#### 📖 Помощь
- 📘 Встроенная инструкция
- 🎬 Видео на YouTube и RuTube

#### 🎯 Основной функционал
- ⚡ Автоматический выстрел (автовыстрел) при наведении прицела на цель / противника
- ⏱️ Настройка задержки перед выстрелом (кастомные тайминги реакции) ⚙️
- ⌨️ Быстрое включение и отключение по горячей клавише (хоткею) 🔘
- 🛡️ Безопасная работа и обход систем защиты ввода 🔒

## 🖥️ Системные требования

| Параметр | Требование |
|:---------|:-----------|
| 🪟 **Операционная система** | Windows 10 / 11 (64-bit) |
| 🖥️ **Разрешение экрана** | 2560×1440 \| 1920×1080 |
| 🎮 **Разрешение окна игры** | 2560×1440 \| 1920×1080 (рекомендовано) |
